## 仓库内容

### 🧮 calculator.py - 简易计算器
一个带详细注释的 Python 计算器，适合入门学习。
包含加法、减法、乘法、除法四种运算，每一行都有解释，帮你看懂代码原理。

运行方式：
```bash
python calculator.py
```

### 🍅 study_timer.py - 番茄学习计时器
帮你专注学习的小工具，包含：
- 番茄钟倒计时（25分钟专注 + 5分钟休息）
- 学习记录功能
- 学习时长统计总结

运行方式：
```bash
python study_timer.py
```
